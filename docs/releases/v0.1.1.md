배포 방식만 바꾼 판입니다. 번역·폰트·그래픽은 v0.1과 같습니다.

**원본 일본판 이미지에 적용하는 전체 패치입니다.** v0.1을 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

- ISO 통째 xdelta 대신 파일 단위 패처로 배포합니다. 덤프·변환 방법에 따라 MD5가 다른 이미지(WBFS, WBFS에서 변환한 ISO 등)에도 적용됩니다.
- 패치 크기가 131MB에서 약 7MB로 줄었습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `TotsugekiFamicomWarsVS_KO_v0.1.1.zip` | 원본 일본판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 적용 방법

1. zip을 풀고 원본 이미지를 `패치하기.bat` 위에 끌어다 놓습니다.
2. 원본과 같은 폴더에 `Totsugeki!! Famicom Wars VS (Korean) [RBWJ01].iso`(원본이 WBFS면 `.wbfs`)가 생깁니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
