- 1편 한글 패치와 같은 방식(맑은 고딕, 흰 글씨·검은 테두리·그림자)으로 장면 폰트 58벌을 새로 만들었습니다.
- 타이틀 로고, 뒤로 버튼, 리모컨 스트랩 경고 화면, Wii 메뉴 채널 배너, 세이브 데이터 로고를 한글화했습니다.
