글꼴을 바꾸고 HOME 버튼 메뉴를 한글화한 판입니다.

**원본 일본판 이미지에 적용하는 전체 패치입니다.** 이전 버전을 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

- 대사·메뉴 한글 글꼴을 G마켓 산스로 바꿨습니다.
- HOME 버튼 메뉴의 글씨(닫기, Wii 메뉴로, 리셋, 설명서, Wii 리모컨 설정 등)를 한글화했습니다.
- 「금색 별」「은색 별」을 음성과 같은 「골드 스타」「실버 스타」로 바꿨습니다.
- 넘치던 확인 창·설명 문장의 줄을 나눴습니다(이름 변경, 파일 삭제, 조준 이동 영역 등).

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `RBWJ_KPatch_v0.1.3.zip` | 원본 일본판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 지원 형식

| 원본 | 결과 |
|---|---|
| ISO (정본 덤프, WBFS에서 변환한 ISO 등) | ISO |
| WBFS | WBFS |
| CISO, WIA, WDF | ISO |
| RVZ · NKit | 지원 안 함. ISO로 변환·복원한 뒤 적용 |

덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.

## 적용 방법

1. zip을 풀고 원본 이미지(ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다. 원본을 같은 폴더에 넣고 더블클릭해도 됩니다.
2. `완료`가 나올 때까지 기다립니다(1~3분).
3. 원본과 같은 폴더에 결과 파일이 생깁니다.
   - ISO 원본 → `Totsugeki!! Famicom Wars VS (Korean) [RBWJ01].iso`
   - WBFS 원본 → `Totsugeki!! Famicom Wars VS (Korean) [RBWJ01].wbfs`

결과 형식을 바꾸려면 패처 폴더의 PowerShell에서 `powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"`처럼 결과 확장자를 지정합니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 오류 메시지와 해결 방법은 동봉한 `README_한국어.txt`를 참고하세요.
